# Architecture — `netprobe-kit`

- `netprobe_kit.analyzer`: Pure-Python `ipaddress` bogon/sinkhole classifier, local-vs-control DNS divergence engine, HTTP blockpage/captive-portal detector, TLS SNI reset & SAN mismatch analyzer, and SHA-256 `NetworkEvidenceBundle` builder.
- `netprobe_kit.cli`: Forensic evidence bundle demonstration CLI.
